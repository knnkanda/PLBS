# PLBS Maker

P/L（損益計算書）とB/S（貸借対照表）を同じ画面で確認する、ブラウザ完結型のMVPです。

- 基準日をカレンダー入力（`input type="date"`）に変更。
- 主要な項目名・見出しを日本語 / Englishの併記に整理。
- 当期利益の純資産に対する比率を追加。

## 比率の用語

画面上の「当期利益の純資産比率 / Net income to equity ratio」は、このアプリ内の説明用指標です。

`当期利益 ÷ 純資産 × 100`

ROE（自己資本利益率）とは異なります。ROEは通常、期首・期末の平均自己資本を分母にします。この指標は、当期利益が期末純資産に対してどの程度の規模かを示し、繰越利益剰余金への加減を理解する補助表示です。配当、その他の包括利益、自己株式などは含まれないため、純資産の増加額を意味しません。

## 入力と保存

- 文字情報を持つPDFのテキスト抽出に対応。
- スキャン画像PDFはOCR未対応。
- 入力値はブラウザのlocalStorageに保存し、次回起動時に復元します。
- P/Lは会計期間、B/Sは基準日として別管理します。
